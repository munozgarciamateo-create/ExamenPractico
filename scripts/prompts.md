# Prompts utilizados en el examen

**Proyecto:** Tienda de Artículos Deportivos (Kotlin + Jetpack Compose)
**Herramienta de IA:** Claude (uso permitido en el examen)

> Nota: los prompts de este documento fueron reformulados y ordenados para que se entiendan mejor. Reflejan lo que se pidió a la IA en cada etapa, pero no son una copia literal de la conversación.

---

## Checkpoint 1: Diseño de clases

### Prompt 1.1: Diagrama de clases
```
Necesito el diagrama de clases para una aplicación sobre una tienda de
artículos deportivos. Debe ser lo más sencillo posible, pero tiene que
incluir los atributos, métodos y relaciones de cada clase.
Esta es la consigna del examen: [consigna completa].
```

### Prompt 1.2: Diagrama como imagen
```
Genera el diagrama de clases anterior como imagen PNG o JPG para
poder subirla a mi repositorio de GitHub.
```

### Prompt 1.3: Commits con Git
```
Según los checkpoints de la consigna, explícame paso a paso cómo hacer
cada commit en Git y subirlo a GitHub. Estoy usando una Mac y la
Terminal.
```

---

## Checkpoint 2: Implementación

### Prompt 2.1: Clases en Kotlin
```
Implementa en Kotlin las clases del diagrama (Categoria, Producto,
Cliente y Pedido), aplicando conceptos de Programación Orientada a
Objetos. Explícame también cómo agregarlas a mi proyecto en
Android Studio.
```

### Prompt 2.2: Rol de MainActivity
```
¿Qué debo hacer con MainActivity en esta etapa del proyecto?
```

### Prompt 2.3: Clases en un solo archivo
```
¿Puedo poner todas las clases en un solo archivo? Muéstrame el código
con las cuatro clases juntas.
```

### Prompt 2.4: Segundo commit
```
Ayúdame a hacer el commit del Checkpoint 2 desde la Terminal y a
verificar que se subió bien a GitHub.
```

### Prompt 2.5: Alcance del commit
```
Subí todo el proyecto en el commit del Checkpoint 2, pero creo que solo
debía subir las clases. ¿Está mal?
```

---

## Checkpoint 3: Scripts

### Prompt 3.1: Organización de los prompts
```
En este examen se permite usar IA. Ayúdame a reformular y organizar los
prompts que utilicé, agrupándolos por checkpoint, para subirlos como
scripts del examen en el tercer commit.
```
